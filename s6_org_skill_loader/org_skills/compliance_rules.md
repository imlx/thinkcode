# 合规审查要点（组织沉淀版）

> 条目来源：《关于进一步加强商业银行小微企业授信尽职免责工作的通知》
> （中国银监会，2018年）。逐条出处见《思政编码坊实践数据集（备查）》S6表，
> 禁止编造。

## 一、尽职免责与不得免责的边界

- **尽职免责六种情形**：符合规定条件的小微企业授信业务，相关人员已按规定履职的，可免除全部或部分责任（具体情形以通知原文为准）。
- **不得免责五种情形**：
  1. 弄虚作假，隐瞒真实情况或提供虚假材料；
  2. 内外勾结，协助借款人套取信贷资金；
  3. 重大失误，未按制度要求履行基本审查义务；
  4. 索取、收受经济利益或不当利益；
  5. 其他依法依规不得免责的情形。

## 二、尽职评议程序要求

1. **回避要求**：参与评议的人员与评议事项存在利害关系的，应当回避。
2. **评议结论三类**：尽职 / 需要改进 / 不尽职；结论应当有事实依据并书面记录。
3. **责任认定公示与档案管理**：认定结果按规定公示，评议材料完整归档、可追溯。

## 三、审查要点

- 先看程序：调查、审查、审批、贷后各环节是否留痕；
- 再看实质：风险揭示是否充分、结论是否与证据匹配；
- 最后看操守：是否存在利益输送与道德风险。
