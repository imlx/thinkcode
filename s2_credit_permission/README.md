# 案例 s2：Tool Use 与权限管理——权责对等的制度意识

岗位权限配置：客户经理持客户书面授权方可查询征信；授信额度审批必须两名审批官双签，同一操作员不能发起又审批；大额划转强制双人复核。

## 思政映射

- 工具注册与调度字典 → 岗位授权清单
- permission 元数据（角色/级别/风险）→ 权责对等：权限即责任
- 默认拒绝（Deny by Default）→ 底线思维：法无授权不可为
- 双人复核（dual approval）→ 用权受监督：双签制的技术实现
