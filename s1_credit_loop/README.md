# 案例 s1：Agent Loop——观察、思考、行动的闭环思维

信贷审批「客户尽调—风险研判—授信执行」闭环：客户经理采集企业征信、财务报表与舆情，形成授信结论并自动附加客户适当性评估。数据为公开信息脱敏代号（A/B/C）引用。

## 思政映射

- 观察（Observe）→ 调查研究：没有调查就没有发言权
- 思考（Think）→ 政治判断力、政治领悟力、政治执行力
- 行动（Act）→ 务实作风：空谈误国、实干兴邦
- 系统提示词价值目标约束 → 金融工作的政治性、人民性

## 运行

```bash
python s1_credit_loop/credit_loop.py
```

```bash
export LLM_API_KEY=你的密钥
export LLM_BASE_URL=https://api.deepseek.com/v1   # OpenAI 兼容服务均可
export LLM_MODEL=deepseek-chat
```
